Всё, что ниже, сделано с помощью панели вверху этой заметки. Никаких настроек, никаких плагинов. Выделите текст, и панель будет действовать на него. Щёлкните в пустой строке, и она начнёт что-то новое.

## Слова

Слово можно сделать **жирным**, *курсивом* или ***и тем, и другим***. Его можно зачеркнуть, вот ~~так~~. Его можно <u>подчеркнуть</u>. Мелкое пишут <sub>нижним индексом</sub>, а степени <sup>верхним индексом</sup>.

Текст может быть <span style="color: #e03131">красным</span>, <span style="color: #1971c2">синим</span>, <span style="color: #2f9e44">зелёным</span> или любым из девяти цветов.

Его можно ==выделить жёлтым== или <mark style="background-color: rgba(64, 192, 87, 0.35)">зелёным</mark>.

Кнопка **Aa** меняет размер и шрифт. Текст может быть <span style="font-size: 0.85em">мелким</span>, обычным или <span style="font-size: 1.6em">крупным</span>. Он может быть <span style="font-family: ui-sans-serif, system-ui, sans-serif">простым</span>, <span style="font-family: ui-serif, Georgia, Cambria, serif">с засечками</span> или <span style="font-family: ui-monospace, SFMono-Regular, Menlo, monospace">моноширинным</span>.

## Где стоят слова

<p style="text-align: center;">Этот абзац выровнен по центру.</p>

<p style="text-align: right;">А этот сдвинут вправо.</p>

Выравнивание перемещает весь абзац, никогда не отдельное слово. Поставьте курсор в абзац и воспользуйтесь кнопкой выравнивания.

## Списки

- Обычный пункт
- Ещё один
  - Нажмите Tab, чтобы сдвинуть строку внутрь
    - И ещё раз

1. Пронумерованный шаг
2. Второй шаг
3. Вставьте шаг в любом месте, и номера исправятся сами

- [x] Отмеченный флажок

- [ ] Флажок

  - [ ] Нажмите Tab, чтобы сдвинуть задачу

  - [ ] Отметьте флажок, чтобы увидеть анимацию

- [ ] Нажмите Shift и Tab, чтобы уменьшить отступ

## Выноски

Выноска является цветным блоком для того, что читатель не должен пропустить.

> [!tip]+ Совет
> Щёлкните заголовок выноски, чтобы свернуть её.

> [!warning]+ Предупреждение
> У каждого вида свой цвет и свой значок.

> [!danger]+ Опасность
> Видов девять. Меню **Вставить** показывает их все.

## Код

Код сохраняет свои отступы и раскрашивается в зависимости от языка.

```js
export function seal(note, key) {
  const nonce = randomBytes(24);
  return xchacha20poly1305(key, nonce).encrypt(note);
}
```

```python
def rolling_mean(values, window):
    return [sum(values[i:i + window]) / window
            for i in range(len(values) - window + 1)]
```

## Ссылки

Их два вида, и они намеренно выглядят по-разному.

- Веб-ссылка открывает сайт: [privacynotes.app](https://privacynotes.app/ru)
- Ссылка на заметку открывает другую вашу заметку: [[Как защищены ваши заметки]]

Для обеих есть кнопка на панели. Цепочка создаёт веб-ссылку. Скобки создают ссылку на заметку: они показывают ваши заметки, и вы выбираете нужную. Ввод `[[` делает то же самое.

Ссылка на заметку не обязана выглядеть как название заметки. Введите название, черту, а затем слова, которые хотите видеть на странице: [[Как защищены ваши заметки|эти слова]] открывают ту заметку.
