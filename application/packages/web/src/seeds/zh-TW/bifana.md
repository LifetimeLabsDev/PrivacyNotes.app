Bifana 是葡萄牙的豬肉三明治。薄切豬肉用蒜頭、白酒和啤酒慢煮，再夾進能吸滿醬汁的麵包裡。這是 PrivacyNotes 創辦人自己的食譜，也是他最愛的一道菜，終於寫下來，免得失傳。

![夾在酥脆麵包裡的 Bifana，醬汁流到盤子上。](/onboarding/bifana.webp)

<p style="text-align: center"><strong>一個鍋。大約半小時。餵飽四個餓的人。</strong></p>

## 你需要什麼

| 食材 | 份量 |
| --- | --- |
| 豬里肌 | 1 公斤 |
| 洋蔥 | 中型 2 顆 |
| 蒜頭 | 6 瓣 |
| 白酒 | 250 毫升 |
| 啤酒 | 330 毫升 |
| 番茄糊 | 1 大匙 |
| 紅椒粉 | 1 大匙 |
| 鹽 | 1 小匙 |
| 黑胡椒 | 1 小匙 |
| 味精 | 1 小匙 |
| 奶油 | 1 大匙 |
| 月桂葉 | 3 片 |
| 辣椒 | 你敢放多少就放多少 |

鍋裡的油：無味的油、橄欖油、豬油或牛油都行。開著的那罐就好。

這道菜很好商量。沒有的就跳過。想換成別的就換。一樣會好吃。

## 開始之前

- [ ] 把豬肉切成薄片
- [ ] 把洋蔥切好
- [ ] 蒜頭壓碎後先放一邊，快結束時才下鍋
- [ ] 把啤酒和白酒開了

> [!tip] 薄到什麼程度才算薄
> 目測就好。有人要薄得像紙，有人想要多一點口感。沒有規定，鍋子是你的。這裡建議薄得像紙：3 到 5 公釐。表面積越多，味道越夠。

## 怎麼煮

1. 在寬鍋裡把油燒到 **非常熱**。
2. 豬肉平鋪一層下鍋。大火煎香，但在整片變褐之前就停手。
3. 加入洋蔥、番茄糊、紅椒粉、鹽、胡椒和味精。一起炒大約兩分鐘。
4. 倒入 **啤酒**，丟進月桂葉。冒泡的時候把鍋底的焦香刮起來。
5. 轉小火。燉 **10 分鐘**。
6. 加入 **白酒**、壓碎的蒜頭和奶油。再燉 **10 分鐘**。
7. 嚐一口，把鹽、胡椒和辣度調到位。

> [!tip] 蒜頭為什麼要晚放
> 燉了半小時的蒜頭味道會變平。壓碎後在快結束時下鍋，才留得住那股嗆勁。這是大多數人做錯的一步。

醬汁該有一點小小的衝擊，不必到辣，剛好察覺得到就好。

## 上桌

<p style="text-align: center"><span style="font-family: ui-serif, Georgia, Cambria, serif">酥脆的麵包。法棍。軟餐包。三種都對。</span></p>

配飯可以。配義大利麵也可以。晚上十一點站著用碗跟叉子吃，一樣可以。

> [!info] 不吃豬肉，或不用酒
> 雞肉、牛肉和羊肉都撐得住同樣的做法。要拿掉酒的話，用高湯代替啤酒和白酒，再淋一點醋。
