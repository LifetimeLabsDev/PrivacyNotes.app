كل ما يلي صُنع بالشريط أعلى هذه الملاحظة. بلا إعدادات، وبلا إضافات. حدِّد نصًّا فيعمل الشريط عليه. انقر في سطر فارغ فيبدأ شيئًا جديدًا.

## الكلمات

يمكنك جعل كلمة **عريضة**، أو *مائلة*، أو ***الاثنتين معًا***. ويمكنك شطبها، ~~مثل هذه~~. ويمكنك <u>تسطيرها</u>. الخط الصغير يذهب إلى <sub>أسفل السطر</sub>، والأسس إلى <sup>أعلاه</sup>.

يمكن أن يكون النص <span style="color: #e03131">أحمر</span> أو <span style="color: #1971c2">أزرق</span> أو <span style="color: #2f9e44">أخضر</span> أو أي لون من تسعة ألوان.

ويمكن أن يكون ==مظللًا بالأصفر== أو <mark style="background-color: rgba(64, 192, 87, 0.35)">بالأخضر</mark>.

زر **Aa** يغيّر الحجم والخط. يمكن أن يكون النص <span style="font-size: 0.85em">صغيرًا</span> أو عاديًّا أو <span style="font-size: 1.6em">كبيرًا</span>. ويمكن أن يكون <span style="font-family: ui-sans-serif, system-ui, sans-serif">بسيطًا</span> أو <span style="font-family: ui-serif, Georgia, Cambria, serif">بذيول</span> أو <span style="font-family: ui-monospace, SFMono-Regular, Menlo, monospace">ثابت العرض</span>.

المربع الملوَّن صندوق بلون مميز لشيء يجب ألا يفوت القارئ.

> [!tip]+ نصيحة
> انقر أيقونته لطيّه.

> [!warning]+ تحذير
> لكل نوع لونه وأيقونته.

> [!danger]+ خطر

> [!fold]- طي

## الحواشي السفلية

تُبقي الحاشية السفلية المصدر أو التعليق الجانبي خارج النص.[^1] اكتب `[^1]` بعد كلمة، أو اختر **حاشية سفلية** من قائمة **إدراج**. انقر على الرقم الصغير للانتقال إلى الحاشية.

تُفتح الكتلة الطويلة مطويّة، ليبقى باقي الملاحظة قريبًا. الزر تحتها يعرض كل الأسطر.

```js
const WORDS_PER_MINUTE = 200;

export function readingStats(markdown) {
  const text = markdown
    .replace(/!\[[^\]]*\]\([^)]*\)/g, ' ')
    .replace(/\[([^\]]*)\]\([^)]*\)/g, '$1')
    .replace(/[#*_~`>|-]/g, ' ');

  const words = text.split(/\s+/).filter(Boolean);
  const headings = markdown.match(/^#{1,6} /gm) ?? [];
  const tasks = markdown.match(/^\s*- \[[ x]\] /gm) ?? [];
  const done = tasks.filter((task) => task.includes('[x]'));

  return {
    words: words.length,
    minutes: Math.max(1, Math.round(words.length / WORDS_PER_MINUTE)),
    headings: headings.length,
    tasks: tasks.length,
    done: done.length,
  };
}

export function summary(stats) {
  const parts = [`${stats.words} words`, `${stats.minutes} min read`];
  if (stats.headings > 0) {
    parts.push(`${stats.headings} sections`);
  }
  if (stats.tasks > 0) {
    parts.push(`${stats.done} of ${stats.tasks} tasks done`);
  }
  return parts.join(' · ');
}

export function isLongRead(stats) {
  return stats.minutes >= 10;
}
```

أما القطعة القصيرة داخل الجملة فتبدو هكذا: `هذه`.

## الروابط

هناك نوعان، ويبدوان مختلفين عن قصد.

- رابط الويب يفتح موقعًا: [privacynotes.app](https://privacynotes.app/ar)
- رابط بين الملاحظات يفتح ملاحظة أخرى من ملاحظاتك: [[كيف تُحمى ملاحظاتك]]

لكليهما زر في الشريط. السلسلة تصنع رابط ويب. والأقواس تصنع رابطًا بين الملاحظات: تسرد ملاحظاتك فتختار التي تقصدها. وكتابة `[[` تفعل الشيء نفسه.

ويمكن للرابط بين الملاحظات أيضًا أن يفتح الملاحظة عند أحد عناوينها. اكتب `#` بعد العنوان واختر العنوان الفرعي: [[كيف تُحمى ملاحظاتك#من يملك مفتاحك]] يفتح تلك الملاحظة عند القسم الخاص بالمفتاح. وأيقونة الرابط بجانب أي عنوان في المخطط التفصيلي تنسخ لك رابطًا كهذا.
