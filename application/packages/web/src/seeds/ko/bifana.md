비파나는 포르투갈식 돼지고기 샌드위치예요. 얇게 썬 돼지고기를 마늘, 화이트와인, 맥주에 뭉근히 끓이고, 소스를 머금는 빵에 끼워요. PrivacyNotes 창업자 본인의 조리법이자 가장 좋아하는 음식이에요. 잃어버리지 않으려고 이제야 적어 두었어요.

![바삭한 빵에 끼운 비파나. 소스가 접시로 흘러내린다.](/onboarding/bifana.webp)

<p style="text-align: center"><strong>냄비 하나. 삼십 분쯤. 배고픈 네 사람 몫.</strong></p>

## 준비물

| 재료 | 분량 |
| --- | --- |
| 돼지 등심 | 1 kg |
| 양파 | 중간 크기 2개 |
| 마늘 | 6쪽 |
| 화이트와인 | 250 ml |
| 맥주 | 330 ml |
| 토마토 페이스트 | 1큰술 |
| 파프리카 가루 | 1큰술 |
| 소금 | 1작은술 |
| 검은 후추 | 1작은술 |
| MSG | 1작은술 |
| 버터 | 1큰술 |
| 월계수 잎 | 3장 |
| 고추 | 감당할 만큼 |

팬에 쓸 기름은 향이 없는 기름, 올리브유, 라드, 소기름 중 아무거나 좋아요. 열려 있는 걸 쓰세요.

이 요리는 웬만한 건 다 받아줘요. 없는 건 빼세요. 더 좋아하는 걸로 바꾸세요. 그래도 잘 돼요.

## 시작하기 전에

- [ ] 돼지고기를 얇게 썰어요
- [ ] 양파를 썰어요
- [ ] 마늘을 으깨서 따로 두세요. 마지막쯤에 들어가요
- [ ] 맥주와 와인을 따요

> [!tip] 얼마나 얇아야 얇은 건가요
> 눈대중으로 하세요. 종이처럼 얇게 원하는 사람도 있고, 씹는 맛을 더 원하는 사람도 있어요. 정해진 규칙은 없고, 당신의 냄비예요. 여기서 권하는 건 종이처럼 얇게, 3에서 5밀리미터예요. 겉면이 넓을수록 맛이 붙어요.

## 만드는 법

1. 넓은 팬에 기름을 **아주 뜨겁게** 달궈요.
2. 돼지고기를 한 겹으로 넣어요. 세게 지지되, 전체가 갈색이 되기 전에 멈춰요.
3. 양파, 토마토 페이스트, 파프리카, 소금, 후추, MSG를 넣어요. 다 같이 2분쯤 볶아요.
4. **맥주**를 붓고 월계수 잎을 떨어뜨려요. 끓는 동안 팬 바닥에 눌은 것을 긁어요.
5. 불을 줄여요. **10분** 뭉근히 끓여요.
6. **와인**, 으깬 마늘, 버터를 넣어요. **10분** 더 끓여요.
7. 맛을 봐요. 소금, 후추, 고추를 맞춰요.

> [!tip] 마늘을 늦게 넣는 이유
> 삼십 분을 끓인 마늘은 맛이 밋밋해져요. 으깨서 마지막쯤 넣으면 날이 살아 있어요. 사람들이 가장 많이 틀리는 단계예요.

소스에는 작은 발길질이 있어야 해요. 맵지는 않게요. 알아챌 만큼이면 충분해요.

## 접시 위에서

<p style="text-align: center"><span style="font-family: ui-serif, Georgia, Cambria, serif">바삭한 빵. 바게트. 부드러운 롤빵. 셋 다 맞아요.</span></p>

밥도 어울려요. 파스타도 어울려요. 밤 열한 시에 서서 그릇에 포크로 먹어도 좋아요.

> [!info] 돼지고기 없이, 또는 술 없이
> 닭고기, 소고기, 양고기도 같은 방식으로 돼요. 술을 빼려면 맥주와 와인 대신 육수를 쓰고 식초를 한 바퀴 둘러 주세요.
