Puoi portare qui quattro tipi di cose: note, voci di diario, segnalibri e password.

Partono tutte dallo stesso posto: **Impostazioni > Importa ed esporta**.

## Cosa puoi portare

| Hai | Arriva come | Si porta dietro |
| --- | --- | --- |
| Note da un'altra app | Note | Tag, cartelle, link tra note, allegati |
| Un export di Apple Journal | Voci di diario | Foto, video, memo vocali, luoghi |
| Segnalibri del browser | Segnalibri | Titoli e icone dei siti |
| Un export di password | Voci della cassaforte | Accessi, carte, chiavi, codici 2FA |

## Note

- [ ] Esporta le tue note dalla vecchia app
- [ ] Trascina il file in un punto qualsiasi di questa finestra
- [ ] Apri cinque note a cui tieni e controllale

Le nostre guide all'importazione sono qui: [privacynotes.app/it/help](https://privacynotes.app/it/help)

> [!tip] Tieni il vecchio export per un mese
> Importalo, usa l'app per qualche settimana, poi cancella il file. Non c'è fretta, e provando non puoi perdere nulla.

## Diario

- [ ] Metti la cartella `AppleJournalEntries` in un file zip e trascinalo qui
- [ ] Apri la vista **Diario** e scrivi di oggi

Una voce di diario contiene più del testo. Sopra l'area di scrittura ci sono i tracciamenti: umore, sonno, energia, passi e altri. Compila quelli che ti interessano e lascia perdere il resto. Dopo due settimane l'app inizia a mostrarti degli schemi.

[[Sabato: monte Fuji]] è una voce completa, con tutti i tracciamenti.

## Segnalibri

- [ ] Esporta i segnalibri del browser come file `.html`
- [ ] Importa quel file: **Impostazioni > Importa ed esporta > Importa > Segnalibri del browser**

Puoi anche incollare un link in una nota vuota. Titolo e icona del sito arrivano da soli: [privacynotes.app/it/help/import/browser-bookmarks](https://privacynotes.app/it/help/import/browser-bookmarks)

## Password

- [ ] Importa un file `.json` di Bitwarden, o il `.csv` delle password del browser
- [ ] **Cancella quel file subito dopo**

Come importare le password del browser: [privacynotes.app/it/help/import/browser-passwords](https://privacynotes.app/it/help/import/browser-passwords)

> [!warning] Un export di password è in chiaro
> Chi apre quel file legge ogni password che contiene. Importalo, controlla la **Cassaforte**, poi cancella il file e svuota il cestino.

La cassaforte contiene accessi, carte, chiavi SSH e codici 2FA. Usa la stessa serratura delle tue note, descritta in [[Come sono protette le tue note]].
