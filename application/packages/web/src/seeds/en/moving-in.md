You can bring four kinds of thing across: notes, journal entries, bookmarks and passwords.

They all start in the same place: **Settings > Import & Export**.

## What you can bring

| You have | It arrives as | It keeps |
| --- | --- | --- |
| Notes from another app | Notes | Tags, folders, note-links, attachments |
| An Apple Journal export | Journal entries | Photos, videos, voice memos, places |
| Browser bookmarks | Bookmarks | Titles and site icons |
| A password export | Vault items | Logins, cards, keys, 2FA codes |

## Notes

- [ ] Export your notes from your old app
- [ ] Drop the file anywhere in this window
- [ ] Open five notes you care about and check them

You can find our import guides here: [privacynotes.app/help](https://privacynotes.app/help)

> [!tip] Keep the old export for a month
> Import it, use the app for a few weeks, then delete the file. There is no hurry, and no way to lose the original by trying.

## Journal

- [ ] Put your `AppleJournalEntries` folder in a zip file and drop it in
- [ ] Open the **Journal** view and write today

A journal entry holds more than text. Above the writing area sit the trackers: mood, sleep, energy, steps and others. Fill in the ones you care about and ignore the rest. After two weeks the app starts showing you patterns.

[[Saturday: Mount Fuji]] is a finished entry, trackers and all.

## Bookmarks

- [ ] Export your browser bookmarks as an `.html` file
- [ ] Import that file: **Settings > Import & Export > Import > Browser bookmarks**

You can also paste a link into an empty note. The title and the site icon arrive on their own: [privacynotes.app/help/import/browser-bookmarks](https://privacynotes.app/help/import/browser-bookmarks)

## Passwords

- [ ] Import a Bitwarden `.json` file, or your browser's password `.csv`
- [ ] **Delete that file straight afterwards**

How to import browser passwords: [privacynotes.app/help/import/browser-passwords](https://privacynotes.app/help/import/browser-passwords)

> [!warning] A password export is plain text
> Anyone who opens that file can read every password in it. Import it, check the **Vault**, then delete the file and empty your trash.

The Vault holds logins, cards, SSH keys and 2FA codes. It uses the same lock as your notes, which [[How your notes are protected]] describes.
