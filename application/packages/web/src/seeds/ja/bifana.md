ビファナはポルトガルの豚肉サンドイッチです。薄切りの豚肉をにんにく、白ワイン、ビールでじっくり煮て、ソースを吸うパンにはさみます。これはPrivacyNotesの創業者自身のレシピで、いちばん好きな食べものです。失われないように、ようやく書き残しました。

![かりっとしたパンにはさんだビファナ。ソースが皿に流れている。](/onboarding/bifana.webp)

<p style="text-align: center"><strong>鍋ひとつ。30分ほど。おなかを空かせた4人分。</strong></p>

## 材料

| 材料 | 分量 |
| --- | --- |
| 豚ロース | 1 kg |
| 玉ねぎ | 中2個 |
| にんにく | 6かけ |
| 白ワイン | 250 ml |
| ビール | 330 ml |
| トマトペースト | 大さじ1 |
| パプリカパウダー | 大さじ1 |
| 塩 | 小さじ1 |
| 黒こしょう | 小さじ1 |
| うま味調味料 | 小さじ1 |
| バター | 大さじ1 |
| ローリエ | 3枚 |
| 唐辛子 | 好きなだけ |

鍋に使う油は、くせのない油、オリーブオイル、ラード、牛脂のどれでもかまいません。開いているものを使ってください。

このレシピはとても寛容です。ないものは省いてください。好きなものに置き換えてください。それでもおいしくできます。

## 始める前に

- [ ] 豚肉を薄く切ります
- [ ] 玉ねぎを切ります
- [ ] にんにくをつぶして、脇によけておきます。入れるのは終わり近くです
- [ ] ビールとワインを開けます

> [!tip] 薄いとはどれくらいか
> 目分量でかまいません。紙のように薄くしたい人もいれば、噛みごたえを残したい人もいます。決まりはありませんし、あなたの鍋です。ここでのおすすめは紙のように薄く、3から5ミリです。表面が増えるほど、味がのります。

## 作り方

1. 広い鍋で油を**しっかり熱く**なるまで熱します。
2. 豚肉を重ならないように入れます。強く焼きつけますが、全体が茶色くなる前で止めます。
3. 玉ねぎ、トマトペースト、パプリカ、塩、こしょう、うま味調味料を加えます。2分ほど一緒に炒めます。
4. **ビール**を注ぎ、ローリエを落とします。煮立つあいだに鍋底の焦げをこそげ取ります。
5. 火を弱めます。**10分**煮ます。
6. **ワイン**、つぶしたにんにく、バターを加えます。さらに**10分**煮ます。
7. 味をみます。塩、こしょう、唐辛子を整えます。

> [!tip] にんにくを遅く入れる理由
> 30分煮たにんにくは味が平たくなります。つぶして終わり近くに入れると、香りの角が残ります。ここを間違える人がいちばん多いです。

ソースには軽い刺激があるくらいがちょうどいいです。辛くはしません。気づく程度で十分です。

## 盛りつけ

<p style="text-align: center"><span style="font-family: ui-serif, Georgia, Cambria, serif">かりっとしたパン。バゲット。やわらかいロールパン。どれも正解です。</span></p>

ご飯にも合います。パスタにも合います。夜11時に立ったまま、ボウルとフォークで食べるのもありです。

> [!info] 豚肉なしでも、お酒なしでも
> 鶏肉、牛肉、羊肉でも同じように作れます。お酒を抜くときは、ビールとワインの代わりにだしを使い、酢をひと回しかけてください。
