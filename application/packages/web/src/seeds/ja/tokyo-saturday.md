---

5時にホテルを出ました。電車で2時間、街はきれいに消えました。

![頂に雪をいただく富士山。桜の枝が縁取っている。](/onboarding/fuji.webp)

湖のほとりでは桜が咲いていました。その後ろに富士山があり、午前中はずっと雲ひとつありませんでした。1週間いても頂上を見られないことがある、と地元の人は言います。私たちは6時間見えていました。

| 何を | いつ |
| --- | --- |
| 起床 | 05:10 |
| 山が最初に見えた時刻 | 08:40 |
| 就寝までの歩数 | 28,400 |

> 国じゅうの絵はがきに載っています。それでも目の前に立つと、やはり効きます。

一日の大半は湖のまわりを歩きました。帰りにとんかつとビールを1杯。11時前に眠りました。家では起きないことです。

今夜の睡眠スコアは==82==、昨日の==41==のあとで。[[金曜日：到着]]はきつかった。
