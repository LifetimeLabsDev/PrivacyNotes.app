ทุกอย่างด้านล่างสร้างด้วยแถบเครื่องมือด้านบนของโน้ตนี้ ไม่ต้องตั้งค่า ไม่ต้องใช้ปลั๊กอิน เลือกข้อความแล้วแถบเครื่องมือจะทำงานกับข้อความนั้น คลิกในบรรทัดว่างแล้วแถบเครื่องมือจะเริ่มสิ่งใหม่

## คำ

คุณทำให้คำเป็น**ตัวหนา** *ตัวเอียง* หรือ***ทั้งสองอย่าง***ได้ ขีดฆ่าได้แบบ~~นี้~~ <u>ขีดเส้นใต้</u>ได้ ตัวเล็กใช้<sub>ตัวห้อย</sub> และเลขยกกำลังใช้<sup>ตัวยก</sup>

ข้อความเป็น<span style="color: #e03131">สีแดง</span> <span style="color: #1971c2">สีน้ำเงิน</span> <span style="color: #2f9e44">สีเขียว</span> หรือสีใดก็ได้จากเก้าสี

ข้อความ==ไฮไลต์สีเหลือง==ได้ หรือ<mark style="background-color: rgba(64, 192, 87, 0.35)">สีเขียว</mark>

ปุ่ม **Aa** เปลี่ยนขนาดและแบบอักษร ข้อความเป็น<span style="font-size: 0.85em">ตัวเล็ก</span> ปกติ หรือ<span style="font-size: 1.6em">ตัวใหญ่</span>ได้ เป็นแบบ<span style="font-family: ui-sans-serif, system-ui, sans-serif">เรียบ</span> <span style="font-family: ui-serif, Georgia, Cambria, serif">มีเชิง</span> หรือ<span style="font-family: ui-monospace, SFMono-Regular, Menlo, monospace">ความกว้างเท่ากัน</span>ก็ได้

## ตำแหน่งของข้อความ

<p style="text-align: center;">ย่อหน้านี้จัดกึ่งกลาง</p>

<p style="text-align: right;">ย่อหน้านี้ชิดขวา</p>

การจัดแนวจะย้ายทั้งย่อหน้า ไม่เคยย้ายเพียงคำเดียว วางเคอร์เซอร์ในย่อหน้าแล้วใช้ปุ่มจัดแนว

## รายการ

- รายการสัญลักษณ์ธรรมดา
- อีกรายการหนึ่ง
  - กด Tab เพื่อเยื้องบรรทัดเข้าไป
    - และอีกครั้ง

1. ขั้นตอนที่มีหมายเลข
2. ขั้นตอนที่สอง
3. แทรกขั้นตอนตรงไหนก็ได้ แล้วหมายเลขจะแก้ไขเอง

- [x] ช่องที่ติ๊กแล้ว

- [ ] ช่องทำเครื่องหมาย

  - [ ] กด Tab เพื่อเยื้องงาน

  - [ ] ติ๊กช่องเพื่อดูแอนิเมชัน

- [ ] กด Shift และ Tab เพื่อลดการเยื้อง

```js
export function seal(note, key) {
  const nonce = randomBytes(24);
  return xchacha20poly1305(key, nonce).encrypt(note);
}
```

```python
def rolling_mean(values, window):
    return [sum(values[i:i + window]) / window
            for i in range(len(values) - window + 1)]
```
