ถึงตอนเที่ยง หลังจากได้นอนแค่สามชั่วโมง

![ตรอกแคบในโตเกียวยามค่ำคืน ประดับด้วยโคมกระดาษสีแดง](/onboarding/tokyo-night.webp)

รถไฟเข้าเมืองคือสิ่งแรกที่ทำให้ฉันแปลกใจ ไม่มีใครพูดคุยกันบนรถไฟเลย รถไฟมาตรงเวลาทุกวินาที บนชานชาลามีตู้ขายกาแฟกระป๋องร้อน

> [!warning] เตือนตัวเอง
> ห้ามงีบ อยู่ให้ถึงสามทุ่ม ไม่อย่างนั้นทั้งสัปดาห์จะพัง

มื้อเย็นอยู่ในตรอกหลังสถานี ในร้านที่มีหกที่นั่ง ไม่มีเมนูภาษาอังกฤษ ฉันเลยชี้ที่รูปบนผนัง สิ่งที่มาเสิร์ฟคือสึเคเมง: บะหมี่เย็นที่จุ่มกินกับน้ำซุปร้อน

- [x] รอดจากเที่ยวบิน
- [x] หาโรงแรมให้เจอ
- [ ] นอนให้เหมือนคนปกติ
