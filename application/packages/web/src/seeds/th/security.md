> [!info]- ทุกโน้ตถูกเข้ารหัสบนอุปกรณ์ของคุณ ก่อนจะถูกจัดเก็บที่ใดก็ตาม
> &nbsp;

![ตารางโน้ตในฐานข้อมูลจริงของเรา เนื้อหาของโน้ตแต่ละรายการเป็นข้อความยาวที่อ่านไม่ออกหนึ่งก้อน](/onboarding/database.webp)

นี่คือฐานข้อมูลจริงของเราในซูริก ไม่ใช่ภาพวาด โน้ตของคุณจะเข้าไปอยู่ในคอลัมน์ `ciphertext` ไบต์ที่เข้ารหัสแล้วคือทั้งหมดที่เราเก็บ ไม่ว่าคุณจะเลือกตัวเลือกใดด้านล่าง

## จะเกิดอะไรขึ้นเมื่อคุณเขียนโน้ต

1. วลี 12 คำของคุณกลายเป็นกุญแจ ขั้นตอนนี้เกิดขึ้นบนอุปกรณ์ของคุณ
2. โน้ตถูกเข้ารหัสด้วยกุญแจนั้นบนอุปกรณ์ของคุณ นี่คือวิธีที่โน้ตถูกบันทึกบนดิสก์ของคุณเอง และวิธีที่โน้ตเดินทางมาถึงเรา
3. เราได้รับโน้ตที่เข้ารหัสแล้วและจัดเก็บไว้ ภาพหน้าจอด้านบนคือหน้าตาของมัน
4. อุปกรณ์ใดก็ตามที่มีวลีเดียวกันจะสร้างกุญแจเดียวกันและเปิดโน้ตได้

## ใครถือกุญแจของคุณ

ทุกตัวเลือกเข้ารหัสโน้ตบนอุปกรณ์ของคุณ สิ่งที่ต่างกันคือวลีของคุณอยู่ที่ไหน

| ตัวเลือก | วลีของคุณอยู่ที่ไหน | สิ่งที่คุณได้ |
| --- | --- | --- |
| **ล็อกอิน เราเก็บกุญแจให้** | บนเซิร์ฟเวอร์ของเรา แบบเข้ารหัส | อุปกรณ์ใหม่เข้าสู่ระบบได้ด้วยล็อกอินนั้นอย่างเดียว |
| **ล็อกอิน กุญแจอยู่ในอุปกรณ์ของคุณ** | อยู่กับคุณ ไม่มีที่อื่น | เข้าสู่ระบบด้วย Google, Apple หรือ GitHub และยังถือกุญแจเอง |
| **ใช้วลีอย่างเดียว ไม่ต้องล็อกอิน** | อยู่กับคุณ ไม่มีที่อื่น | ไม่มีอีเมล ไม่มีชื่อ ไม่มีล็อกอินเลย |

สองตัวเลือกด้านล่างหมายความว่าเราอ่านโน้ตไม่ได้ แม้จะถูกบังคับก็ตาม ตัวเลือกแรกแลกข้อนี้กับความสะดวก วลีของคุณอยู่บนเซิร์ฟเวอร์ของเราภายใต้กุญแจของเรา อุปกรณ์ใหม่จึงต้องการแค่ล็อกอินของคุณ หากวันหนึ่งเซิร์ฟเวอร์ของเราถูกเจาะ กุญแจนั้นอาจรั่วไหลได้

เข้าสู่ระบบด้วย Google, Apple หรือ GitHub ใช่ไหม? สลับระหว่างสองตัวเลือกแรกได้ภายหลังใน **การตั้งค่า > ความปลอดภัย > วลีของคุณ** ส่วนบัญชีที่ใช้วลีอย่างเดียว วลีจะอยู่กับคุณเสมอ

> [!warning] เก็บสำเนาวลีของคุณเอง
> วลีของคุณเปิดโน้ตของคุณ หากทำหาย ไม่มีใครกู้คืนให้คุณได้ รวมถึงเราด้วย <span style="color: #e03131">จดลงกระดาษวันนี้เลย</span>
