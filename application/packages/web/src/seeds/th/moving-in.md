คุณนำข้อมูลเข้ามาได้สี่แบบ: โน้ต บันทึกประจำวัน บุ๊กมาร์ก และรหัสผ่าน

ทุกแบบเริ่มต้นที่เดียวกัน: **การตั้งค่า > Import & Export**

## สิ่งที่นำเข้ามาได้

| สิ่งที่คุณมี | จะเข้ามาเป็น | สิ่งที่ยังคงอยู่ |
| --- | --- | --- |
| โน้ตจากแอปอื่น | โน้ต | แท็ก โฟลเดอร์ ลิงก์ระหว่างโน้ต ไฟล์แนบ |
| ไฟล์ส่งออกจาก Apple Journal | บันทึกประจำวัน | รูปภาพ วิดีโอ บันทึกเสียง สถานที่ |
| บุ๊กมาร์กเบราว์เซอร์ | บุ๊กมาร์ก | ชื่อและไอคอนเว็บไซต์ |
| ไฟล์ส่งออกรหัสผ่าน | รายการในตู้นิรภัย | ล็อกอิน บัตร กุญแจ รหัส 2FA |

## โน้ต

- [ ] ส่งออกโน้ตจากแอปเก่าของคุณ
- [ ] ลากไฟล์มาวางที่ใดก็ได้ในหน้าต่างนี้
- [ ] เปิดโน้ตห้ารายการที่คุณสนใจแล้วตรวจดู

คู่มือการนำเข้าของเราอยู่ที่นี่: [privacynotes.app/th/help](https://privacynotes.app/th/help)

> [!tip] เก็บไฟล์ส่งออกเก่าไว้สักเดือน
> นำเข้าไฟล์ ใช้แอปสักสองสามสัปดาห์ แล้วค่อยลบไฟล์ ไม่ต้องรีบ และการลองก็ไม่มีทางทำให้ต้นฉบับหาย

## บันทึกประจำวัน

- [ ] บีบอัดโฟลเดอร์ `AppleJournalEntries` เป็นไฟล์ zip แล้วลากมาวาง
- [ ] เปิดมุมมอง **บันทึกประจำวัน** แล้วเขียนเรื่องของวันนี้

บันทึกประจำวันเก็บได้มากกว่าข้อความ เหนือพื้นที่เขียนจะมีตัวติดตาม: อารมณ์ การนอน พลังงาน จำนวนก้าว และอื่น ๆ กรอกเฉพาะที่คุณสนใจ ส่วนที่เหลือข้ามไปได้ หลังจากสองสัปดาห์ แอปจะเริ่มแสดงรูปแบบให้คุณเห็น

[[วันเสาร์: ภูเขาไฟฟูจิ]] คือตัวอย่างบันทึกที่สมบูรณ์ พร้อมตัวติดตามครบ

## บุ๊กมาร์ก

- [ ] ส่งออกบุ๊กมาร์กเบราว์เซอร์เป็นไฟล์ `.html`
- [ ] นำเข้าไฟล์นั้น: **การตั้งค่า > Import & Export > นำเข้า > บุ๊กมาร์กจากเบราว์เซอร์**

คุณยังวางลิงก์ลงในโน้ตเปล่าได้ด้วย ชื่อและไอคอนเว็บไซต์จะมาเอง: [privacynotes.app/th/help/import/browser-bookmarks](https://privacynotes.app/th/help/import/browser-bookmarks)

## รหัสผ่าน

- [ ] นำเข้าไฟล์ `.json` จาก Bitwarden หรือไฟล์รหัสผ่าน `.csv` จากเบราว์เซอร์ของคุณ
- [ ] **ลบไฟล์นั้นทันทีหลังจากนำเข้า**

วิธีนำเข้ารหัสผ่านจากเบราว์เซอร์: [privacynotes.app/th/help/import/browser-passwords](https://privacynotes.app/th/help/import/browser-passwords)

> [!warning] ไฟล์ส่งออกรหัสผ่านเป็นข้อความธรรมดา
> ใครก็ตามที่เปิดไฟล์นั้นจะอ่านรหัสผ่านทุกรายการในไฟล์ได้ นำเข้าไฟล์ ตรวจดู **ตู้นิรภัย** แล้วลบไฟล์และล้างถังขยะ

ตู้นิรภัยเก็บล็อกอิน บัตร กุญแจ SSH และรหัส 2FA ใช้กุญแจเดียวกับโน้ตของคุณ ซึ่ง [[โน้ตของคุณได้รับการปกป้องอย่างไร]] อธิบายไว้
