ออกจากโรงแรมตอนตีห้า นั่งรถไฟสองชั่วโมง แล้วเมืองก็หายไปเฉย ๆ

![ภูเขาไฟฟูจิที่มียอดปกคลุมด้วยหิมะ ล้อมกรอบด้วยดอกซากุระ](/onboarding/fuji.webp)

ซากุระบานอยู่ริมทะเลสาบ ฟูจิตั้งอยู่ด้านหลังโดยไม่มีเมฆบังตลอดช่วงเช้า คนที่นี่บอกว่ามาทั้งสัปดาห์ก็อาจไม่ได้เห็นยอดเลย เราได้เห็นอยู่หกชั่วโมง

| อะไร | เมื่อไร |
| --- | --- |
| ตื่นนอน | 05:10 |
| เห็นภูเขาครั้งแรก | 08:40 |
| จำนวนก้าวก่อนนอน | 28,400 |

> ภูเขานี้อยู่บนโปสการ์ดทุกใบในประเทศ แล้วเมื่อคุณได้ยืนอยู่ตรงหน้า มันก็ยังทำให้ทึ่งอยู่ดี

เดินรอบทะเลสาบเกือบทั้งวัน กินทงคัตสึระหว่างทางกลับ กับเบียร์หนึ่งแก้ว หลับก่อนห้าทุ่ม ซึ่งไม่เคยเกิดขึ้นที่บ้าน

คะแนนการนอนคืนนี้ ==82== หลังจากเมื่อวาน ==41== [[วันศุกร์: ถึงแล้ว]] ค่อนข้างหนัก
