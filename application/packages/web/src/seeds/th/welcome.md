## ลองเลยตอนนี้

คลิกที่ท้ายบรรทัดนี้แล้วพิมพ์คำหนึ่งคำ โน้ตจะบันทึกเอง ไม่มีปุ่มบันทึก

แถบเครื่องมือด้านบนเปลี่ยนหน้าตาของข้อความได้: **ตัวหนา** *ตัวเอียง* หัวเรื่อง เช็กลิสต์ <span style="color: #f08c00">สี</span> <span style="font-size: 1.25em; font-family: ui-serif, Georgia, Cambria, serif">แบบอักษร</span> ลิงก์

## สามโน้ตที่ควรเปิดดู

| โน้ต | มีไว้เพื่ออะไร |
| --- | --- |
| [[ย้ายเข้ามา]] | การนำโน้ต บุ๊กมาร์ก และรหัสผ่านเข้ามา |
| [[ทุกอย่างที่ markdown ทำได้ที่นี่]] | ทุกวิธีจัดรูปแบบข้อความในหน้าเดียว |
| [[โน้ตของคุณได้รับการปกป้องอย่างไร]] | ใครถือกุญแจของคุณ และเราเห็นอะไรได้บ้าง |

## สิ่งที่ควรทำวันนี้หนึ่งอย่าง

- [ ] หา **<mark style="background-color: rgba(51, 154, 240, 0.35)">วลี 12 คำ</mark>** ของคุณใน **การตั้งค่า > ความปลอดภัย > วลีของคุณ** จดลงบนกระดาษ แล้วเก็บไว้ในที่ปลอดภัย

วลีนั้นคือสิ่งที่เปิดโน้ตของคุณ จะเก็บไว้ที่ไหนเป็นทางเลือกของคุณ และคุณเปลี่ยนทางเลือกนั้นได้ทุกเมื่อ [[โน้ตของคุณได้รับการปกป้องอย่างไร]] อธิบายตัวเลือกทั้งสามแบบ

> [!tip] ไม่มีอะไรที่นี่เป็นของถาวร
> ทุกโน้ตในตู้นิรภัยนี้เป็นตัวอย่าง รวมถึงโน้ตนี้ด้วย แก้ไข ย้าย หรือลบทิ้งได้เลย
