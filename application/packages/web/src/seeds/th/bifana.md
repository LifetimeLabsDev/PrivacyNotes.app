บิฟานาคือแซนด์วิชหมูสไตล์โปรตุเกส หมูหั่นบางเคี่ยวในกระเทียม ไวน์ และเบียร์ แล้วใส่ลงในขนมปังที่ซึมซับซอสไว้ นี่คือสูตรของผู้ก่อตั้ง PrivacyNotes เองและเป็นอาหารจานโปรดของเขา ซึ่งในที่สุดก็ได้จดไว้เพื่อไม่ให้หายไป

![บิฟานาในขนมปังกรอบ ซอสเจิ่งอยู่บนจาน](/onboarding/bifana.webp)

<p style="text-align: center"><strong>หม้อเดียว ราวครึ่งชั่วโมง อิ่มได้สี่คนที่หิวจัด</strong></p>

## สิ่งที่ต้องใช้

| วัตถุดิบ | ปริมาณ |
| --- | --- |
| สันนอกหมู | 1 กก. |
| หัวหอม | ขนาดกลาง 2 หัว |
| กระเทียม | 6 กลีบ |
| ไวน์ขาว | 250 มล. |
| เบียร์ | 330 มล. |
| มะเขือเทศเข้มข้น | 1 ช้อนโต๊ะ |
| ปาปริกา | 1 ช้อนโต๊ะ |
| เกลือ | 1 ช้อนชา |
| พริกไทยดำ | 1 ช้อนชา |
| ผงชูรส | 1 ช้อนชา |
| เนย | 1 ช้อนโต๊ะ |
| ใบกระวาน | 3 ใบ |
| พริก | มากเท่าที่กล้า |

ไขมันสำหรับกระทะ: น้ำมันพืช น้ำมันมะกอก น้ำมันหมู หรือไขมันวัว อะไรที่มีอยู่ก็ได้

สูตรนี้ยืดหยุ่นมาก ข้ามสิ่งที่ไม่มีได้ เปลี่ยนเป็นสิ่งที่ชอบกว่าก็ได้ ก็ยังอร่อยเหมือนเดิม

## ก่อนเริ่ม

- [ ] หั่นหมูให้บาง
- [ ] หั่นหัวหอม
- [ ] บดกระเทียมแล้วพักไว้ ใส่ตอนใกล้เสร็จ
- [ ] เปิดเบียร์และไวน์

> [!tip] บางแค่ไหนถึงเรียกว่าบาง?
> กะเอาด้วยตา บางคนชอบบางจนเป็นแผ่น บางคนอยากได้เนื้อสัมผัสมากกว่า ไม่มีกฎตายตัว และหม้อเป็นของคุณ ที่นี่แนะนำให้บางเป็นแผ่น: 3 ถึง 5 มม. พื้นผิวมากขึ้น รสชาติก็มากขึ้น

## วิธีทำ

1. ตั้งไขมันในกระทะกว้างจน**ร้อนจัด**
2. ใส่หมูเป็นชั้นเดียว จี่ให้ไฟแรง แต่หยุดก่อนที่จะเป็นสีน้ำตาลทั้งหมด
3. ใส่หัวหอม มะเขือเทศเข้มข้น ปาปริกา เกลือ พริกไทย และผงชูรส ผัดรวมกันราวสองนาที
4. เท**เบียร์**และใส่ใบกระวาน ขูดส่วนที่ติดก้นกระทะออกขณะที่เดือด
5. ลดไฟลงอ่อน เคี่ยว **10 นาที**
6. ใส่**ไวน์** กระเทียมบด และเนย เคี่ยวต่ออีก **10 นาที**
7. ชิมดู ปรุงเกลือ พริกไทย และพริกให้พอดี

> [!tip] ทำไมต้องใส่กระเทียมทีหลัง
> กระเทียมที่เคี่ยวนานครึ่งชั่วโมงจะรสจืดไป บดแล้วใส่ตอนใกล้เสร็จ กระเทียมจะยังคงความจัดจ้าน นี่คือขั้นตอนที่คนมักทำผิด

ซอสควรมีความเผ็ดนิดหน่อย ไม่ถึงกับเผ็ดร้อน แค่พอให้รู้สึก

## บนจาน

<p style="text-align: center"><span style="font-family: ui-serif, Georgia, Cambria, serif">ขนมปังกรอบ บาแก็ต ขนมปังนุ่ม ถูกทั้งสามแบบ</span></p>

กินกับข้าวก็ได้ พาสต้าก็ได้ ชามกับส้อม ยืนกินที่เคาน์เตอร์ตอนห้าทุ่มก็ได้เช่นกัน

> [!info] ไม่ใช้หมู หรือไม่ใช้แอลกอฮอล์
> ไก่ เนื้อวัว และเนื้อแกะ ทำแบบเดียวกันได้ทั้งหมด หากไม่ใช้แอลกอฮอล์ ให้ใช้น้ำซุปแทนเบียร์และไวน์ แล้วเติมน้ำส้มสายชูเล็กน้อย
